# 🌟 Functional Calendar by Kirill

A modern, stylish, and minimalist interactive calendar with Duolingo-style gamification elements and responsive design. Built with a focus on clean functionality and custom aesthetics.

---

## 🎨 Design Features (Themes)
The project supports two neon themes with instant switching:
- 🟠 **Dark Theme:** Black background with rich neon-orange accents (`#ff5e00`).
- 🔵 **Light Theme:** White background with clean neon-blue accents (`#00f0ff`).

---

## 🚀 Key Features
- **Google Calendar-style Grid:** Convenient month grid, current day highlight, and any date selection.
- **Structured Event Input:** Add events specifying time, location, participants, and notification settings.
- **Gamification (Duolingo Style):** Streak counter (days without missing) and a dynamic productivity progress bar.
- **Responsiveness:** 
  - 📱 On mobile devices — vertical interface (everything at your fingertips).
  - 💻 On PCs and tablets — convenient two-column dashboard (calendar on the left, daily plans on the right).
- **Local Storage:** All notes are saved directly in the browser's `localStorage` and persist after page reloads.

---

## 🛠 Technologies
- **HTML5** (Semantic markup)
- **CSS3** (CSS Grid, Flexbox, CSS variables, `@media` queries)
- **JavaScript (ES6+)** (State management, date handling, LocalStorage)
- **FontAwesome** (Icons)

# 🌟 Functional Calendar by Kirill
Современный, стильный и минималистичный интерактивный календарь с элементами геймификации в стиле Duolingo и адаптивным дизайном. Разработано с акцентом на чистый функционал и кастомную эстетику.

---

## 🎨 Особенности дизайна (Темы)
Проект поддерживает две неоновые темы с мгновенным переключением:
- 🟠 **Тёмная тема:** Черный фон с насыщенными неоново-оранжевыми акцентами (`#ff5e00`).
- 🔵 **Светлая тема:** Белый фон с чистыми неоново-синими акцентами (`#00f0ff`).

---

## 🚀 Основной функционал
- **Календарь а-ля Google Calendar:** Удобная сетка месяцев, подсветка текущего дня и выбор любой даты.
- **Структурированный ввод заметок:** Добавление событий с указанием времени, места, участников и настройки уведомлений.
- **Геймификация (Duolingo Style):** Счетчик стриков (дней без пропусков) и динамический полосатый прогресс-бар продуктивности.
- **Адаптивность (Responsive):** - 📱 На мобильных устройствах — вертикальный интерфейс (всё под рукой).
  - 💻 На ПК и планшетах — удобный двухколоночный дашборд (календарь слева, планы на день справа).
- **Локальное хранение (LocalStorage):** Все заметки сохраняются прямо в браузере и не пропадают при перезагрузке.
